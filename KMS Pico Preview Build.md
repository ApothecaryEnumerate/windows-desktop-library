## 🧪 Tentang Program Beta

Versi **Beta** KMS Pico adalah build **eksperimental** yang dirilis untuk pengujian publik sebelum peluncuran resmi. Build ini mencakup peningkatan kompatibilitas terbaru dengan Windows, termasuk dukungan untuk versi **23H2** dan **24H2**.

## 🪜 Instalasi Terpandu

### Langkah 1 — Siapkan Lingkungan Uji

**Prioritas:** jalankan dulu di mesin virtual.

Jika menggunakan sistem nyata, buat titik pemulihan:

**Control Panel → System → System Protection → Create**

### Langkah 2 — Nonaktifkan Perlindungan Sementara

**Windows Security → Virus & threat protection → Manage settings → Real-time protection → Off**.

Tambahkan pengecualian:

```
Settings → Privacy & security → Windows Security
→ Virus & threat protection → Exclusions → Add folder
```

### Langkah 3 — Ekstrak Paket Beta

Klik kanan file → **Extract All…** → pilih folder khusus.

### Langkah 4 — Jalankan sebagai Administrator

Cari `KmsPicoBeta.exe` → klik kanan → **Run as administrator**.

> 💡 Jika SmartScreen muncul: **More info → Run anyway**.

### Langkah 5 — Asisten Beta

Saat dijalankan, asisten memandu proses:

1. 🔍 Deteksi build Windows
2. 🧠 Pemilihan kunci GVLK otomatis
3. 🖥️ Instalasi layanan KMS Beta
4. 🎫 Penerbitan token 180 hari

### Langkah 6 — Aktifkan Windows

Klik **Aktifkan Sekarang**. Aktivasi berjalan otomatis.

### Langkah 7 — Verifikasi Aktivasi

Command Prompt sebagai administrator:

```bash
slmgr /xpr
```

Hasil yang diharapkan: **"activated permanently"**.

Detail lengkap:

```bash
slmgr /dlv
```

### Langkah 8 — Validasi Renovasi Otomatis

Buka **Task Scheduler → Library** dan konfirmasi tugas **KmsPicoBeta** aktif.

### Langkah 9 — Kumpulkan Umpan Balik

Build beta memiliki modul **umpan balik terintegrasi**:

- 🐛 Laporkan bug
- 💡 Sarankan perbaikan
- 📊 Kirim statistik anonim (opsional)

### Langkah 10 — Pulihkan Antivirus

Aktifkan kembali perlindungan dan tambahkan folder KMS ke pengecualian.

## 🛠️ Pemecahan Masalah Beta

| Masalah | Penyebab | Solusi |
|---------|----------|--------|
| ❌ Aktivasi gagal | Defender aktif | Nonaktifkan dan uji ulang |
| ❌ Layanan tidak jalan | Hak akses | Jalankan sebagai admin |
| ❌ Error 0xC004F074 | Tanpa jaringan | Periksa koneksi |
| ❌ Layar hitam | Konflik beta | Safe Mode → hapus |
| ❌ Dasbor tidak terbuka | Port terpakai | Ubah di config.ini |
| ❌ Umpan balik gagal kirim | Proxy | Nonaktifkan proxy |
| ❌ Renovasi gagal | Tugas dinonaktifkan | Aktifkan ulang KmsPicoBeta |
| ❌ Office tidak aktif | Tab salah | Gunakan tab Office |
| ❌ Crash saat aktivasi | Build tidak kompatibel | Laporkan bug |
| ❌ UAC tidak muncul | Akun biasa | Gunakan akun admin |
